# web effecter

브라우저에서 실행되는 8슬롯 기타 이펙터 실험실입니다. 정적 파일만 사용하므로 GitHub Pages에서 그대로 호스팅할 수 있습니다.

## 실행

로컬에서는 프로젝트 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`을 여세요. GitHub Pages에서는 이 파일들을 `hyoutenka/hyoutenka.github.io` 저장소의 게시 루트에 놓고 Pages를 활성화하면 `https://hyoutenka.github.io/`에서 실행됩니다. HTTPS 또는 localhost 환경이어야 오디오 입력과 AudioWorklet을 사용할 수 있습니다.

1. **오디오 시작**을 누릅니다.
2. 오디오 인터페이스의 기타 입력을 연결하거나 기타 DI 녹음 파일을 불러옵니다.
3. 8개 노드를 눌러 이펙트를 배치하고 파라미터와 바이패스를 조정합니다.
4. 출력 장치를 선택하고 헤드폰으로 모니터링합니다. 출력 선택은 지원 브라우저에서만 동작합니다.

`Electric violin` 프리셋은 **Compressor → SAW Synth → Violin IR → EQ → Chorus → Reverb** 순서입니다. SAW Synth는 단음 입력의 기본 주파수를 추적해 SAW를 합성하며, **Attack**으로 소리가 시작되는 속도를 조절합니다. 이어지는 Violin IR 노드는 기본 합성 바디 IR로 시험하거나 사용자가 가진 실제 바이올린 측정 IR을 불러올 수 있습니다. V 키 또는 VIOLIN 버튼으로 SAW와 IR을 함께 켜고 끕니다. 기본 합성 IR은 실제 바이올린에서 측정한 파일이 아니므로 동일한 음색을 보장하지 않습니다. 화음·잡음·급격한 음 전환에서는 피치 인식이 불안정할 수 있습니다. 오디오 파일과 IR은 브라우저 안에서만 처리하며 업로드하지 않습니다.

입력 장치의 모니터링/루프백 설정과 브라우저 출력이 중복되면 피드백이 생길 수 있습니다. 처음에는 출력 볼륨을 낮추고 헤드폰을 사용하세요. 오디오 지연 시간은 브라우저, 인터페이스 드라이버, 출력 경로에 따라 달라집니다.
